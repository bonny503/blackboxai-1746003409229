# SecureCCTV

## Project Overview
SecureCCTV is a web-based application that provides information about CCTV cameras and installation services for both residential and commercial properties. Users can browse products, learn about installation services, read informative blog posts, and contact the service for quotes and support. The site emphasizes high-quality security solutions, user-friendly interfaces, and professional installation services.

## Installation
To run the SecureCCTV project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/securecctv.git
   ```

2. Navigate into the project folder:
   ```bash
   cd securecctv
   ```

3. Open `index.html` in your web browser. You can click through the various pages such as products, installation, blog, etc.

No specific installation of dependencies is required for this HTML/CSS/JavaScript project; all resources are linked via CDN.

## Usage
- Navigate to the **Home** page to explore information about SecureCCTV services and products.
- Click on **Products** to view and filter available CCTV cameras for sale.
- Visit the **Installation** page to learn about professional installation services.
- Read engaging articles on the **Blog** page that covers security tips and technology updates.
- Contact SecureCCTV using the **Contact** page for inquiries or quotes.

## Features
- **Responsive Design**: The site is mobile-friendly and adjusts seamlessly across different screen sizes.
- **Products Page**: Users can filter CCTV cameras by type (indoor/outdoor) and connection (wired/wireless).
- **Informative Blog**: Contains articles about CCTV technology, installation tips, and industry news.
- **Installation Services**: Detailed explanation of the installation process, including consultations and customer testimonials.
- **Contact Form**: Users can submit inquiries directly to SecureCCTV.

## Dependencies
The project uses the following external libraries linked via CDN:
- [Tailwind CSS](https://tailwindcss.com/)
- [Font Awesome](https://fontawesome.com/)

No additional dependencies are necessary; the project is built primarily using HTML, CSS, and JavaScript.
